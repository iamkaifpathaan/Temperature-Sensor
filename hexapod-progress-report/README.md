# Hexapod Project Progress Report (Group B9)

Mid-project progress report for **Arduino-Based Hexapod for Emergency and Surveillance**
(Dept. of ECE, GCET Greater Noida).

| File | What it is |
|---|---|
| `Hexapod_Progress_Report.pdf` | Report for submission / reading |
| `Hexapod_Progress_Report.docx` | Editable version — paste the KiCad screenshots and photos into the dashed placeholder boxes |
| `make_photos.py` | Prepares the team photos and KiCad screenshots in `figures/` from `photos/src/` |
| `build_report.py` | Generates the .docx and .pdf (needs python-docx, pymupdf, LibreOffice Writer) |
| `make_figures.py` | Generates the diagrams in `figures/` (needs matplotlib) |

Rebuild: `python3 make_figures.py && python3 make_photos.py && python3 build_report.py`

The 3D-printing image boxes in Chapter 8 are intentionally empty: that phase has not started yet.
